# EduGuide AI

## One Platform. Every Exam. Complete Guidance.

EduGuide AI is a smart educational guidance platform that helps students discover, understand, apply for, and prepare for various competitive examinations in one place.

### Features

* Explore competitive exams
* Exam eligibility and syllabus
* Important dates and timelines
* Application guidance
* Learning videos and resources
* AI-powered exam recommendations
* Personalized study plans
* Exam reminders and notifications

### Technologies Used

* HTML
* CSS
* JavaScript

### Project Goal

To reduce confusion and help students find complete competitive exam guidance through one centralized platform.
